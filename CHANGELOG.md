## v0.2 — Foundations Curriculum

Added the first complete curriculum track and strengthened project governance.

### Curriculum

- Added `foundations/README.md` as the Foundations learning path.
- Added **AI History and Evolution**.
- Added **Neural Networks to Transformers**.
- Added **Transformers and Attention**.
- Added **Tokens, Context and Embeddings**.
- Added **Training, Inference and Scaling**.
- Added **Reasoning and Test-Time Compute**.
- Added **Mixture of Experts (MoE)**.
- Added **Multimodal Foundations**.
- Added a **Foundations Capstone** requiring reproducible model comparison, failure classification and an Architecture Decision Record.

### Roadmap architecture

- Expanded the Master Roadmap to 28 connected domains.
- Added staged Learning Phases from AI literacy through the AI Operating System capstone.
- Added explicit competency levels: **Understand → Build → Architect → Lead**.
- Added an evidence-based Assessment Model.

### Governance and quality

- Added the AI Technology Decision Framework.
- Added the Curriculum Authoring Standard.
- Strengthened contribution requirements for evidence, reproducibility, security, economics and vendor neutrality.
- Rebuilt the root README as the main navigation and project entry point.
