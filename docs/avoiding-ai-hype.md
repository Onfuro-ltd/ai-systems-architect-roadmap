# Avoiding AI Hype

AI evolves quickly and creates significant excitement. This project deliberately avoids accepting claims without evaluation.

## Questions Every Technology Must Answer

### Problem

What real problem does this solve?

### Evidence

Is there measurable improvement or only a demonstration?

### Maturity

Is it research, experimental, production-ready or enterprise-ready?

### Trade-offs

What complexity, cost, security or reliability issues does it introduce?

### Decision

Every technology should receive a recommendation:

- Ignore
- Watch
- Experiment
- Adopt
- Build Around

## Principle

A viral demo is not automatically a valuable system component.

The goal is durable capability, not temporary excitement.
