# v1.0 Release Notes — AI Systems Architect Roadmap

Status: **release candidate notes prepared; public tag pending final publication gates.**

## What v1.0 represents

v1.0 is the first release candidate in which the repository presents the complete 28-domain AI Systems Architect curriculum as one authoritative, navigable and evidence-driven architecture roadmap.

## Curriculum

The roadmap now spans foundation models, application engineering, RAG, agents, skills, MCP, memory, orchestration, evaluation, security, system/data architecture, open/local AI, fine-tuning, GPU inference, LLMOps, multimodal/interface/physical AI, economics/routing, enterprise/product/automation/decision systems, domain-specific AI, AI-native operations and the final model-independent AI Operating System capstone.

## Architecture philosophy

The release consistently emphasizes architecture over tools, evidence over demos, deterministic boundaries around probabilistic models, evaluation before autonomy, least privilege, human authority, model independence where practical and cost per successful outcome.

## v1 hardening

- Sanitized reachable repository history and public curriculum examples.
- Restored explicit authoritative homes for all 28 domains.
- Classified legacy and supplemental content without discarding useful historical depth.
- Normalized learning outcomes and evidence-producing exercises.
- Deepened GPU/inference and canonical multimodal curricula.
- Added complete navigation, prerequisites and contributor templates.
- Added a standard-library repository validator and GitHub Actions CI.
- Added version/release policy and publication checklist.

## Known publication gate

A public v1.0 tag must not be created until:

1. maintainers deliberately choose and add the repository license;
2. the cumulative P5 branch is reviewed and merged into `main`;
3. repository-quality CI passes on the exact merged main commit;
4. tag-ready validation passes.

## Validation

Before publication:

```bash
python3 scripts/validate_repository.py --release
python3 scripts/validate_repository.py --tag-ready
```

The second command is expected to fail until the repository license is present.

## Final principle

> v1.0 is a stable architecture-learning checkpoint, not the end of the roadmap's evolution.
