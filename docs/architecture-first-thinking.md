# Architecture First Thinking

## The Shift

Traditional software often starts with features.

AI-native systems require thinking about the complete operating architecture.

## AI System Layers

A mature AI system contains:

```
Models
  ↓
Reasoning and orchestration
  ↓
Skills and workflows
  ↓
Memory and knowledge
  ↓
Tools and integrations
  ↓
Policies and permissions
  ↓
Evaluation
  ↓
Feedback loop
```

## Key Questions

Before adopting a technology:

- Where does it fit in the architecture?
- What dependency does it create?
- What happens if it fails?
- How is quality measured?
- How does it create business value?

## Principle

The best AI systems are engineered systems, not collections of AI tools.
