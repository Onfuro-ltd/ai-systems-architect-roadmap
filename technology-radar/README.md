# AI Technology Radar

Technology is evaluated using five categories.

## BUILD AROUND

Foundational technologies expected to remain strategically important.

## ADOPT

Mature technologies ready for practical use.

## EXPERIMENT

Promising technologies requiring testing.

## WATCH

Interesting but immature or uncertain.

## IGNORE

Low-value, hype-driven or unsuitable approaches.

Each evaluation should consider:

- capability
- maturity
- reliability
- security
- cost
- ecosystem strength
- strategic importance
