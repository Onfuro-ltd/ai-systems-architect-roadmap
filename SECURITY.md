# Security Policy

## Purpose

AI systems require strong security practices because models can interact with data, tools, APIs and business systems.

## Reporting security issues

Please report security concerns privately rather than opening public issues containing sensitive details.

## Security principles

This project promotes:

- least privilege access
- human approval for high-impact actions
- auditability
- secure tool execution
- protected secrets
- evaluation before deployment
- separation between AI reasoning and production permissions

AI systems should be designed assuming failures can occur.
