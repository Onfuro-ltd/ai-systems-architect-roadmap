# AI Systems Architect Roadmap

A practical roadmap for building AI-native systems.

## Vision

This project exists to help founders, engineers, architects and technical leaders understand, design and build serious AI systems.

This is not another list of AI tools.

It is a structured journey from understanding foundation models to designing enterprise AI operating systems.

## Core Principle

AI models will continue to change. Durable advantage comes from understanding and building the layers around models:

- Skills
- Memory
- Knowledge systems
- Tools
- MCP
- Agents
- Evaluation
- Security
- Governance
- Feedback loops

## What this roadmap covers

- AI foundations
- Large language models
- AI application engineering
- RAG and knowledge systems
- Agents and workflows
- Agent harness engineering
- Skills and memory
- MCP and tool use
- Orchestration
- AI infrastructure
- Enterprise AI architecture
- AI-native business systems

## Why this exists

The AI ecosystem moves extremely quickly. Many resources focus on individual tools or hype cycles.

This roadmap focuses on durable concepts, architectural decisions, trade-offs and practical implementation.

The goal is to move from:

> Using AI

To:

> Designing systems powered by AI.

## Technology evaluation philosophy

Every technology should be evaluated through:

- What problem does it solve?
- Why does it exist?
- Where does it fit?
- What are the limitations?
- Is it production ready?
- Should we ignore, watch, experiment, adopt or build around it?
