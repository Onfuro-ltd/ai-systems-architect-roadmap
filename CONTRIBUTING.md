# Contributing to AI Systems Architect Roadmap

Thank you for contributing.

This project is designed as a long-term knowledge resource for building AI-native systems. Contributions should focus on durable principles, architectures, evaluations, and practical lessons rather than temporary tool lists.

## What makes a valuable contribution

Good contributions include:

- AI architecture patterns
- Technology evaluations
- Real implementation lessons
- Security and governance practices
- Agent design patterns
- MCP/tool integration patterns
- Evaluation methodologies
- Case studies

## Technology submissions

When adding a technology or framework, include:

1. What problem does it solve?
2. How does it work?
3. Where does it fit in an AI system?
4. What are the limitations?
5. Production maturity assessment
6. Security considerations
7. Cost considerations
8. Recommendation:

- IGNORE
- WATCH
- EXPERIMENT
- ADOPT
- BUILD AROUND

## Principles

Avoid hype-driven submissions. Explain trade-offs and failure modes.

The objective is not collecting tools. The objective is understanding and building reliable AI systems.
