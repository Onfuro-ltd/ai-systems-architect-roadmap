# Open Source Models, Fine-Tuning & AI Infrastructure v0.8

## Purpose

This section explains how modern AI systems are built when organisations need control over models, data, cost, privacy, and performance.

The goal is not to promote self-hosting everything. The goal is to understand the correct engineering decision:

- when to use frontier APIs;
- when to use open-source models;
- when to fine-tune;
- when to build infrastructure;
- when to avoid unnecessary complexity.

## Core Principle

> The best AI architecture is not the biggest model. It is the right combination of model capability, data, infrastructure, cost, and business requirements.
