# Data Preparation

## Core Principle

> Data quality is often a bigger competitive advantage than model size.

A specialised AI system is only as good as the data used to build, evaluate, and improve it.

## Why Data Matters

Models learn patterns from examples. Poor data creates unreliable behaviour and weak generalisation.

## Data Pipeline

```text
Raw Data

↓

Collection

↓

Cleaning

↓

Labelling

↓

Validation

↓

Training / Evaluation

↓

Feedback Loop
```

## Data Types

### Structured Data

Examples:

- product catalogues;
- sales records;
- inventory data;
- financial data.

### Unstructured Data

Examples:

- documents;
- images;
- conversations;
- videos;
- reviews.

Enterprise AI usually combines both.

## Labelling

High-quality labels are essential for supervised learning.

Examples:

- product classifications;
- defect categories;
- preferred outputs;
- validated business decisions.

## Synthetic Data

Synthetic data can accelerate development when real data is limited, but it must be validated and should supplement rather than replace real examples.

## Evaluation Data

Strong AI systems require separate evaluation datasets:

```text
Training Data

+

Validation Data

+

Real-world Test Data
```

## SEMLIS Relevance

The strategic advantage is building commerce intelligence data:

```text
Marketplace Data

+

Product Information

+

Customer Feedback

+

Business Decisions

+

Human Corrections

↓

Domain Intelligence
```

## Key Lesson

> Proprietary high-quality data combined with strong engineering creates durable AI advantage.
