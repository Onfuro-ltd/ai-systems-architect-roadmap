## Recommended paths

### Full AI systems architect

Follow the [Learning Phases](./learning-phases.md) from Domains 01–02 through Domain 28. Use the [Assessment Model](./assessment-model.md) at each major phase boundary.

### Application and agent engineer

Recommended route: 01–05 → 06–11 → 12–13 → 21 → 24. Add 17 for production operations and 22 for enterprise deployment.

### AI platform and inference engineer

Recommended route: 01–03 → 10 → 12–17 → 21–22 → 28. Add 07/09 when the platform exposes tool-using or orchestrated agents.

### Security and governance architect

Recommended route: 01–03 → 05 → 07 → 09–13 → 17 → 22 → 28. Security is cross-cutting; the route is not permission to ignore security in other domains.

### Multimodal and interface systems engineer

Recommended route: 01–03 → 10–12 → 18 → 19. Add 16 for self-hosted inference, 20 for physical systems and 22 for enterprise governance.

### AI product, automation and decision systems

Recommended route: 01–04 → 10–13 → 21–25 → 26–28. Add 07/09 for tool-enabled automation and 22 for enterprise rollout.

## How to skip a prerequisite responsibly

A learner may skip a recommended prerequisite when they can already produce the relevant mastery evidence: explanation, implementation experience, failure analysis, security judgement, evaluation and architecture decisions. Use the [Competency Levels](./competency-levels.md) and [Assessment Model](./assessment-model.md) rather than relying on self-assessed familiarity.
